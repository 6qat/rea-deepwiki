# DeepWiki

DeepWiki is the in-editor encyclopedia for the code a developer is reading.

## Language

**Article subject**:
The code symbol or diagnostic an article documents.
_Avoid_: target, selection, fake symbol

**Article**:
The encyclopedia page for one article subject.
_Avoid_: wiki page, document

**Follow-up**:
A question about the article on screen.
_Avoid_: chat message, prompt

**Output language**:
The human language in which DeepWiki presents its interface, articles, and follow-ups.
_Avoid_: locale, target language, translation language
